# NPS vs APS Calculator

React + Vite app for comparing National Pension Scheme (NPS) vs Assured Pension Scheme (APS).

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```
3. Open the URL shown in terminal (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```
